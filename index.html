🔬 VLSI/ASIC Engineer (Full Flow)

📘 1. Foundational & RTL

  • Digital logic, CMOS basics, Combinational/Sequential, FSM, metastability, clock domains
  • RTL design with Verilog/SystemVerilog: blocking/non-blocking, parameterized modules, packages, interfaces
  • CDC (Clock Domain Crossing) techniques: 2-flop, gray encoding, FIFOs, handshake
  • Linting (SpyGlass) & CDC checks; Synthesis constraints (.sdc), timing paths, clock definitions

🛠️ 2. Synthesis & STA

  • Logic synthesis: Design Compiler/Genus – area, power, timing trade-offs; multicycle paths, false paths
  • Static Timing Analysis (PrimeTime/Tempus): setup/hold, OCV, AOCV, derates. Timing corners (SS, FF, TT)
  • Low power: UPF flow, power gating, voltage islands, clock gating insertion
  • DFT: Scan chain insertion, ATPG, coverage improvement, boundary scan, JTAG 1149.1, BIST (Memory BIST)

⚙️ 3. Physical Design (PnR)

  • Floorplan: macros placement, power planning (ring/stripes), placement blockage, IO ring
  • Placement: standard cells, congestion analysis, optimization; CTS (Clock Tree Synthesis): skew, latency, buffers
  • Routing: global/detail routing, DRC fixing, signal integrity (crosstalk, shielding)
  • Signoff: DRC/LVS with Calibre/ICV, EM/IR analysis, physical verification

📌 Year-wise Mastery

0-2 Yrs

RTL design, simulation, basic scripts; understand synthesis flow

2-4 Yrs

Own full module PnR, STA closure, tape-out support

4-7 Yrs

Hierarchical design, multi-voltage, advanced node (7nm/5nm), lead engineer

7+ Yrs

SoC integration, chip architect, DFX, team management

🎓 Certifications & Tools

  • VLSI courses: CDAC, IITs (online), Synopsys University, Cadence Academic Network
  • Tool certifications: Physical Design (Innovus/ICC2), STA (PrimeTime), DFT (Tessent)
  • Scripting: Tcl, Python, Perl. Version control: Git, Perforce
  • Reading: "CMOS VLSI Design" (Weste Harris), "Digital Integrated Circuits" (Rabaey)

⚡ Embedded Systems Engineer

🔹 1. Core Embedded Programming

  • Embedded C (pointers, bitwise, volatile, const, static, memory sections), C++ for embedded (RAII, templates, constexpr)
  • ARM Cortex-M (M0/M4/M7) architecture: NVIC, memory map, MPU, SysTick
  • Peripheral drivers: GPIO, UART, I2C, SPI, I2S, Quad SPI, Timers (PWM, capture), ADC, DAC, DMA
  • Interrupt management: priority, nesting, latency, deferred handlers (ISR vs task)
  • Low-level: linker script, startup code, vector table, heap/stack management, bootloader design (SD card, USB DFU, OTA)

🧠 2. RTOS & Middleware

  • FreeRTOS: tasks, queues, semaphores, mutex, event groups, software timers, stream buffers
  • Advanced RTOS: Zephyr (device tree, drivers), ThreadX, Azure RTOS
  • Embedded Linux: Yocto, Buildroot, device tree, kernel modules, char drivers, UIO, SPI/I2C userspace
  • Communication stacks: BLE stack (Nordic SDK), LoRaWAN, MQTT, COAP, LwIP, TCP/IP over Ethernet

🛠️ 3. Toolchain & Debugging

  • IDEs: STM32CubeIDE, Keil MDK, IAR, VS Code + Cortex-Debug, Eclipse
  • Debug probes: J-Link, ST-Link, Black Magic Probe, GDB, Ozone, SystemView, Tracealyzer
  • Hardware tools: oscilloscope, logic analyzer (Saleae), multimeter, spectrum analyzer for EMI issues
  • CI for embedded: Jenkins, GitLab runners, static analysis (Coverity, clang-tidy), unit testing (Ceedling, Unity)

📈 Industry Verticals & Certifications

  • Automotive (AUTOSAR), Medical (IEC 62304), Industrial (PLC, fieldbus), Aerospace (DO-178C), Consumer (smart home, wearables)
  • Certifications: ARM Accredited Engineer, RTOS-specific (FreeRTOS, Zephyr), Embedded Linux (LFCS), SafeRTOS

📶 5G / Telecom Expert

🎯 5G System Engineering

  • 5G NR: numerologies, subcarrier spacing, FR1/FR2, Massive MIMO, beamforming, beam management
  • Protocol stack (CU/DU split): SDAP, PDCP, RLC, MAC, RRC, NGAP, XnAP; F1 interface
  • 5G Core: AMF, SMF, UPF, NRF, NSSF, network slicing, QoS flows, PDU sessions
  • O-RAN architecture: O-Cloud, Near-RT RIC, SMO, xApps/rApps, E2 interface, RAN intelligent controller

📡 RF Planning & Optimization

  • Cell planning: coverage prediction, link budget, propagation models (Okumura-Hata, COST231, Ray-tracing)
  • Drive test tools: TEMS, NEMO, QXDM, XCAL; post-processing: Actix, WindCatcher
  • Optimization KPIs: SINR, RSRP, RSRQ, CQI, BLER, handover success, call drop, throughput
  • SON (Self-Organizing Networks): ANR, MLB, MRO, PCI conflict resolution

📚 Certifications & Path

  • Nokia 5G Cert, Ericsson 5G RAN, Huawei HCIA-5G, CWNA, CCNA/CCNP (Wireless)
  • SDN/NFV: OpenStack, ONAP, VNF, MANO
  • Job ladder: RF Engineer → RAN Optimization → Core Engineer → Solution Architect → CTO track

🎛️ Signal Processing Specialist

📐 Mathematical Deep Dive

  • Discrete-time signals, convolution, correlation, Z-transform, DTFT, DFT/FFT (radix-2, decimation), DCT, Hilbert transform
  • Digital filters: FIR design (window, Parks-McClellan), IIR (Bilinear transform, Butterworth, Chebyshev, Elliptic), lattice filters
  • Adaptive filters: LMS, RLS, affine projection, echo cancellation, noise cancellation (ANC), system identification
  • Multirate: decimation, interpolation, polyphase filters, filter banks, Wavelet transform, subband coding
  • Statistical SP: random processes, spectral density, Wiener filter, Kalman filter, particle filters, estimation/detection theory

🖥️ Application Domains

  • Audio: echo cancellation, speech enhancement, beamforming, MP3/AAC codec basics, pitch detection, MFCC for voice recognition
  • Radar/Sonar: pulse Doppler processing, FMCW ranging, SAR imaging, DOA estimation (MUSIC, ESPRIT), STAP
  • Image/Video: edge detection, image restoration, JPEG compression, motion estimation, H.264 intra prediction, OpenCV integration
  • Biomedical: ECG/EEG filtering, QRS detection, wavelet denoising, seizure prediction

💻 Tools & ML integration

  • MATLAB/Simulink (DSP System Toolbox, Phased Array Toolbox), Python (NumPy, SciPy, PyTorch, Librosa, RFSoC)
  • GNU Radio + USRP for SDR prototyping, Jupyter for algorithm exploration
  • Certifications: IEEE Signal Processing Society, Coursera DSP (EPFL), Deep Learning for Signals (DeepSig)

📡 RF & Microwave Engineer

📐 RF Fundamentals & Design

  • Transmission line modes: microstrip, stripline, CPW, waveguide. Characteristic impedance, reflection, VSWR, return loss
  • Smith chart: impedance matching (L-networks, Pi/T networks, stub matching, λ/4 transformers), Q factor, bandwidth
  • S-parameters: measurement, conversion to Z/Y, stability (K, μ factor), gain circles, noise circles, constant VSWR
  • RF components: LNA design (NF, gain, IP3), Mixer (passive/active, conversion loss), VCO/PLL (phase noise), Power Amplifier (class A, AB, C, E, F, Doherty), RF filters (LC, ceramic, SAW, BAW)
  • Antenna theory: dipole, patch, Yagi, helical, horn, parabolic, array antennas, beam steering, phased arrays, MIMO

🧪 Simulation & Measurement

  • EM simulation: Keysight ADS (RFPro), AWR MWO, HFSS (3D), CST Studio, FEKO, EMPro
  • PCB design for RF: Altium RF, Cadence AWR, controlled impedance, RF shielding, grounding techniques
  • Instrumentation: VNA (2/4 port), Spectrum Analyzer (phase noise, occupied BW), Signal Generator, Noise Figure Meter, Power Meter, Probe station, Anechoic chamber testing

🔧 High-Speed Hardware Design

⚡ Schematics & Component Engineering

  • Component selection: parametric search (DigiKey, Mouser), derating, lifecycle management, alternative sourcing, BOM cost optimization
  • Power electronics: DC-DC converters (Buck, Boost, SEPIC, Ćuk), LDO selection, inrush current, load transient, PSRR, thermal management
  • High-speed interfaces: DDR3/DDR4/DDR5 routing guidelines (length matching, Vref, CA bus), PCIe Gen3/4/5, USB 3.2, HDMI 2.1, MIPI DSI/CSI, Ethernet 10G, SERDES
  • Analog front-end: op-amp circuits, ADC/DAC selection, anti-aliasing filters, precision references, instrumentation amps

📐 PCB Layout & Signal Integrity

  • Stackup design: impedance control (50Ω, 90Ω differential), stackup planning for DDR/PCIe, microstrip/stripline
  • High-speed layout: matched length, via transitions, serpentines, backdrilling, routing layers assignment
  • Signal Integrity: HyperLynx, Ansys SIwave – eye diagram, crosstalk, return loss, TDR simulation, S-parameter extraction
  • Power Integrity: IR drop analysis, decoupling capacitor placement, PDN impedance, resonant modes, AC simulation
  • EMI/EMC design: filtering, shielding, split planes, ferrite beads, pre-compliance testing (radiated/conducted)

🏭 Certification & Tools

  • Altium Designer, Cadence Allegro, OrCAD, Mentor Xpedition, KiCad, Fusion 360
  • IPC CID (Certified Interconnect Designer), IPC 610/620, DFM workshop, Ansys training

✅ ASIC/FPGA Verification (UVM)

📚 SystemVerilog & UVM Deep

  • SV enhancements: OOP, randomization (rand, randc), constraints, inside/dist, post_randomize, functional coverage (covergroup, bins, cross)
  • UVM: component hierarchy (uvm_component, uvm_test, uvm_env, uvm_agent, uvm_driver, uvm_monitor, uvm_sequencer, uvm_scoreboard)
  • Sequences & sequencers: sequence arbitration, virtual sequences, layered sequences, sequence library
  • Register layer (RAL): field access, backdoor/frontdoor, built-in tests
  • Coverage-driven verification: functional coverage points, covergroups, cross coverage, coverage closure metrics

🛠️ Tools & Formal

  • Simulators: Synopsys VCS, Cadence Xcelium, Mentor Questa, Aldec Riviera-PRO
  • Formal verification: JasperGold, VC Formal, property checking (SVA), assertions, assume-guarantee
  • Verification IP (VIP): PCIe, USB, DDR, Ethernet, AXI/AHB. VIP integration, test suite development
  • Scripting: Python, Perl, Tcl for regressions, log parsing, coverage database merging

🌍 Full-Stack IoT Engineer

📟 Device Layer

  • MCUs: ESP32 (WiFi/BT), nRF52 (BLE), STM32WL (LoRa), RP2040/Pico, TI CC1352 (dual-band)
  • Sensor fusion: IMU (MPU6050, BMI160), environmental (BME280, SHT30), GNSS (GPS/GLONASS/QZSS), biosensors (MAX30102)
  • Low-power optimization: deep sleep, wake-up sources, RTC, low-power peripherals, energy profiling
  • Wireless connectivity: LoRaWAN (The Things Network), NB-IoT (SIM7020), LTE-M, Zigbee, Thread/Matter, BLE 5.2 advertising

☁️ Cloud & Analytics

  • AWS IoT Core (MQTT, Device Shadow, Rules Engine, Fleet Provisioning), Azure IoT Hub (DPS, Edge), GCP IoT Core
  • Protocols: MQTT (QoS levels), CoAP, HTTP/2, WebSockets, gRPC
  • Backend: Node-RED, InfluxDB + Telegraf, Grafana dashboards, TimescaleDB, Kafka stream processing
  • Edge AI: TensorFlow Lite Micro, Edge Impulse, microTVM, CMSIS-NN on MCUs
  • OTA (Over-the-Air): MQTT + secure boot (mbedTLS, ATECC608), partition management, rollback protection

🚗 Automotive Electronics (ISO 26262)

🔌 Automotive Comms

  • CAN / CAN FD (ISO 11898), LIN, FlexRay, Automotive Ethernet (AVB, TSN, gPTP), SOME/IP, DoIP
  • Tools: Vector CANoe/CANalyzer, CAPL scripting, CANdelaStudio, vFlash, PREEvision
  • AUTOSAR Classic (CP): BSW, RTE, SW-C, MCAL, CDD, OS tasks, NvM, EcuM, WdgM
  • AUTOSAR Adaptive: POSIX, C++, RESTful, SOM, ara::com, configuration (C++ code generation)

⚠️ Functional Safety & ADAS

  • ISO 26262: ASIL levels (A to D), HARA, FMEA, FTA, safety goals, DIA, fault injection tests
  • ADAS sensors: Radar (24/77GHz), LiDAR (HDL-64E), camera (monocular, stereo), fusion, perception stack (YOLOv8, PointPillars)
  • V2X: DSRC (IEEE 802.11p), C-V2X (Rel-14/15), message sets (BSM, CAM, DENM)
  • Cybersecurity: ISO/SAE 21434, secure boot, HSM (AES, RSA, ECC), evita HSM, SHE, secure OTA

🧠 TinyML / Edge AI Engineer

📊 Model Optimization

  • Quantization: int8, uint8, float16, per-channel, post-training quantization (PTQ), QAT (Quantization-aware training)
  • Pruning: magnitude-based, structured/unstructured, sparsity, lottery ticket hypothesis
  • Distillation: teacher-student, hard/soft labels, feature distillation, TinyBERT
  • Compiler optimization: TFLite Micro, TVM, Glow, XNNPACK, CMSIS-NN, Ethos-U NPU

🧩 Applications & Frameworks

  • Keyword spotting (KWS), wake word detection, Person detection, anomaly detection (vibration, current), predictive maintenance
  • Radio ML: modulation recognition (RML), spectrum sensing, autoencoders for CSI compression, channel estimation with ML
  • Hardware: Edge TPU, NVIDIA Jetson, Kendryte K210, GreenWaves GAP9, ARM Ethos-U55
  • Frameworks: TensorFlow Lite Micro, Edge Impulse, SensiML, STM32Cube.AI, X-CUBE-AI, Neuton TinyML

⚙️ Firmware Engineer

🔧 Bare-metal & RTOS

  • Startup code, vector table relocation, MPU configuration, MMU (Cortex-A), linker scripts
  • Device driver architecture: char, block, network; interrupt coalescing, DMA scatter-gather
  • Bootloader: UART, I2C, SPI, USB DFU, SD card, dual-image, CRC check, secure boot
  • Memory profiling, static analysis, build systems: CMake, Meson, Make

🥇 FPGA / RTL Engineer

📌 High-performance RTL

  • Advanced Verilog/SystemVerilog for synthesis: interfaces, clocking blocks, always_ff, always_comb
  • Timing closure: retiming, floorplanning, incremental compilation, multi-clock constraints
  • High-speed transceivers: GTY/GTH, FPGA hard IP: PCIe, JESD204B, 100G Ethernet
  • HLS (Vitis HLS): C++ to RTL, pipeline directives, array partitioning
  • IP integration: AXI4, custom IP cores, debugging via ChipScope/SignalTap

🤖 Robotics Engineer (ROS2)

🎯 Autonomy & Control

  • ROS2 (Humble/Iron): nodes, topics, services, actions, QoS, lifecycle nodes, launch files
  • Simulation: Gazebo, RViz2, Webots, Isaac Sim, URDF/XACRO, TF2 transforms
  • Navigation: SLAM (Cartographer), AMCL, Nav2, path planning (A*, RRT)
  • Robotic arm: kinematics, MoveIt2, motion planning, ROS2 control
  • Embedded for robotics: micro-ROS, FreeRTOS+ROS2, Teensy, Odrive
